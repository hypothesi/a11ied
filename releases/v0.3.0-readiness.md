2. Build every publishable workspace package.

2. Publish the generated static output from `apps/docs/dist/`.

2. Review `skills/a11lied/agents/openai.yaml` so the description matches the release.
3. Publish the skill bundle from `skills/a11lied/` together with the docs update so agents and humans read the same rules.

## Scope

The WCAG lookup commands of the built CLI, in JSON mode, for the six scenarios CE-02 maps to.

The feature file still described the April 2026 commands. It was updated in the same change so each scenario names the command that exists today:

- `wcag levels` no longer exists. `wcag criteria` with no `--level` returns every level.
- `--version` on `wcag` subcommands is now `--wcag`.
- `wcag search` is now the top-level `search` command.
- `wcag coverage` no longer exists. `wcag show` returns the test method with its axe and ACT rule ids.
- The `inspect` command was removed, so its four scenarios and `05-cli-inspect.feature` were deleted.

## User-surface exercise

All commands ran against `packages/cli/dist/cli.js` built from the working tree.

```sh
node packages/cli/dist/cli.js wcag criteria --json
node packages/cli/dist/cli.js wcag criteria --level AA --wcag 2.1 --json
node packages/cli/dist/cli.js wcag show status-messages --json
node packages/cli/dist/cli.js search "status message" --json
node packages/cli/dist/cli.js wcag show 4.1.3 --json
node packages/cli/dist/cli.js wcag criteria --level AA --wcag 2.0 --json
```

# v0.1.0 release readiness

This file is the explicit release record for the first public milestone.

## release path

### packages

1. Run `npm run standards` from the repo root.
2. Run `npm test` from the repo root.
3. Run `npm run pack:check` to confirm every public workspace packs cleanly.
4. Publish the public workspaces through the `publish-packages` GitHub Actions workflow (or a published GitHub release event).
5. Smoke the released CLI (`a1 doctor`) and the released library and MCP entry points before announcing the release.

### docs

1. Run `npm run build --workspace @a11ied/docs`.
2. Publish the generated static output from `packages/docs/dist/`.
3. Confirm the live site serves the quickstart, install, targets, coverage, applicability, screen reader and testing guides, CLI reference, MCP reference, and API reference routes. `packages/docs/src/lib/nav.ts` lists every route the site should carry.

### agent skill

1. Review `packages/skills/a11ied/SKILL.md` against the released CLI and MCP behavior.
2. Review `packages/skills/a11ied/agents/openai.yaml` so the description matches the release.
3. Publish the skill bundle from `packages/skills/a11ied/` together with the docs update so agents and humans read the same rules.

## release requirements

- all CI checks pass
- one manual macOS VoiceOver smoke run passes
- one manual Windows NVDA smoke run passes
- deferred items below are reviewed and accepted explicitly

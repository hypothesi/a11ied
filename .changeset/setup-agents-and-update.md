`npx a11ied setup` now offers to install `a1` globally, and to add the a11ied skills and MCP server to the AI coding agents it finds, with a checkbox for each. It also asks before it changes system settings for VoiceOver or NVDA. `--yes` accepts every step.

The new `a1 update` command installs the latest version, and `a1`, `a1 --help`, `a1 doctor`, and the audit dashboard show a short notice when one is available. Set `NO_UPDATE_NOTIFIER` to turn the notice off.

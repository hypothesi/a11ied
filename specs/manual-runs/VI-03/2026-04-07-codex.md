## user-surface exercise

I manually exercised the built CLI surface from `/Users/mluedke/code/personal/a11ied/packages/cli/dist/cli.js` against a fresh local fixture server on `http://127.0.0.1:4175`:

```sh
python3 -m http.server 4175 --bind 127.0.0.1
node /Users/mluedke/code/personal/a11ied/packages/cli/dist/cli.js verify --help
node /Users/mluedke/code/personal/a11ied/packages/cli/dist/cli.js verify level --help
node /Users/mluedke/code/personal/a11ied/packages/cli/dist/cli.js verify level AA --url http://127.0.0.1:4175/auth-login.html --target virtual --json
node /Users/mluedke/code/personal/a11ied/packages/cli/dist/cli.js verify level AA --url http://127.0.0.1:4175/auth-login.html --target virtual
```

Observed result:

- `verify --help` exited with code `0` and listed both `criterion` and `level` under the verify family.
- `verify level --help` exited with code `0` and printed the expected `--url`, `--version`, `--target`, `--json`, and `--verbose` options.
- `verify level AA --json` exited with code `4`, returned `requestedScope.kind: "level"`, `requestedScope.level: "AA"`, defaulted to WCAG `2.2`, and emitted a complete criterion matrix with `55` rows. The report did not stop after the first non-pass row.
- The JSON summary reported `24` passes, `1` fail, `25` `needs-manual-review` rows, `3` `not-applicable` rows, and `2` `error` rows. It also preserved both manual-only work and uncovered work in the matrix.
- The JSON matrix included representative cumulative rows from both `A` and `AA`, including `4.1.2`, `2.4.3`, `3.3.8`, and `4.1.3`.
- `verify level AA` in text mode exited with code `4` and printed a readable matrix summary with total and failed counts, verdict and evidence-mode breakdowns, `Manual-only criteria`, `Uncovered criteria`, and a `Rows:` section.
- The text output made one useful limitation obvious instead of hiding it: `2.4.7` and `2.4.11` currently surface as row-level `error` verdicts on the auth fixture because their current probes are still too target-specific. The report continued past them instead of crashing the whole run.

## Scope

This manual run covers the driver lifecycle foundation pass:

- shared driver schemas for readiness, session metadata, state snapshots, and action results
- normalized target adapters for `virtual`, `voiceover`, and `nvda`
- broker-backed persisted session metadata under `.a11lied/state/sessions/`
- real CLI handlers for `drive start`, `drive status`, and `drive stop`

## manual contract exercise

I manually exercised the built contract package from `/Users/mluedke/code/personal/a11ied/packages/contracts/dist/index.js` by parsing both fixture reports and printing the fields that later verification surfaces depend on:

```sh
node --input-type=module -e 'import { readFileSync } from "node:fs"; import { verificationReportSchema } from "./packages/contracts/dist/index.js"; const report = verificationReportSchema.parse(JSON.parse(readFileSync("./packages/contracts/test-fixtures/verification-report.pass.json", "utf8"))); console.log(JSON.stringify({ scope: report.requestedScope.kind, wcagVersion: report.wcagVersion, criterionId: report.criteria[0].criterionId, verdict: report.criteria[0].verdict, evidenceMode: report.criteria[0].evidenceMode, procedureIds: report.criteria[0].procedureIds, spokenPhraseLog: report.criteria[0].evidence[0].patternResult.spokenPhraseLog }, null, 2));'
node --input-type=module -e 'import { readFileSync } from "node:fs"; import { levelVerificationResultSchema, verificationReportSchema } from "./packages/contracts/dist/index.js"; const report = verificationReportSchema.parse(JSON.parse(readFileSync("./packages/contracts/test-fixtures/verification-report.mixed.json", "utf8"))); const level = levelVerificationResultSchema.parse({ level: report.requestedScope.level, wcagVersion: report.wcagVersion, summary: report.summary, criteria: report.criteria, uncoveredCriterionIds: ["3.3.8", "2.4.3"], manualOnlyCriterionIds: ["3.3.8"] }); console.log(JSON.stringify({ scope: report.requestedScope.kind, level: level.level, summary: report.summary, verdicts: report.criteria.map((criterion) => ({ criterionId: criterion.criterionId, verdict: criterion.verdict, evidenceMode: criterion.evidenceMode })), manualOnlyMessages: report.criteria.find((criterion) => criterion.criterionId === "3.3.8").uncoveredWork.map((entry) => entry.message), notCoveredMessages: report.criteria.find((criterion) => criterion.criterionId === "2.4.3").uncoveredWork.map((entry) => entry.message) }, null, 2));'
```

Observed result:

- The passing fixture parsed as a criterion-scoped report for WCAG `2.2`.
- The `4.1.3` row kept verdict `pass`, evidence mode `hybrid`, procedure id `status_message_probe`, and the spoken evidence `Profile saved successfully.`.
- The mixed fixture parsed as a level-scoped report for `AA`.
- The mixed report summary preserved explicit `fail`, `needs-manual-review`, and `not-covered` counts rather than collapsing them into one boolean.
- The `3.3.8` row stayed explicit about manual-only work.
- The `2.4.3` row stayed explicit about uncovered work.

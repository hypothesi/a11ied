Then I used the MCP client to exercise the server:

Observed result:

- MCP tool listing returned 25 tools.
- MCP resource listing returned the criteria, level-list, coverage, verification-strategy, and target resources for WCAG 2.1 and 2.2.
- `criterion_lookup` for `4.1.3` succeeded and returned the same criterion id and shared-contract payload shape used by the CLI.

- `driver_start_session` on `virtual` succeeded and returned a real `sessionId`.

- The returned driver session metadata used a short unix socket path under `/tmp`, which fixed the earlier broker crash from deep temp directories on macOS.
- Driver and verification tool metadata explicitly warned that the tool may launch or drive assistive technology.

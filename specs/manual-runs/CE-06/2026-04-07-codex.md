```sh
node packages/cli/dist/cli.js run pattern landmark_sequence --url http://127.0.0.1:4173/basic-page.html --target virtual --json
node packages/cli/dist/cli.js run pattern heading_sequence --url http://127.0.0.1:4173/basic-page.html --target virtual --json
node packages/cli/dist/cli.js run pattern status_message_probe --url http://127.0.0.1:4173/status-message.html --target virtual --json
node packages/cli/dist/cli.js run pattern dialog_probe --url http://127.0.0.1:4173/dialog.html --target virtual --json
node packages/cli/dist/cli.js run pattern focus_visibility_probe --url http://127.0.0.1:4173/focus-obscured.html --target virtual --json
node packages/cli/dist/cli.js drive start --target virtual --json
node packages/cli/dist/cli.js run pattern landmark_sequence --url http://127.0.0.1:4173/basic-page.html --target virtual --session drv_29413dad-d6b6-4834-8167-bbe5dfe3289a --json
node packages/cli/dist/cli.js drive stop --session drv_29413dad-d6b6-4834-8167-bbe5dfe3289a --json
node packages/cli/dist/cli.js run pattern landmark_sequence --url http://127.0.0.1:4173/basic-page.html --target virtual
```

Observed result:

- `landmark_sequence --json` exited with code `0`, returned `attach-target`, `collect-landmarks`, and `driver-walk` steps, and produced spoken/item logs from the virtual session
- `heading_sequence --json` exited with code `0`, preserved the single heading `Basic content page`, and returned the `heading-order:passed` assertion
- `status_message_probe --json` exited with code `0`, returned the `trigger-status-message` step, included `Profile saved successfully.` in `spokenPhraseLog`, and recorded `focusChangedUnexpectedly: false`
- `dialog_probe --json` exited with code `0` and returned `focus-entry:passed`, `focus-containment:passed`, and `close-behavior:passed`
- `focus_visibility_probe --json` exited with code `0`, returned assertion rows, and included one browser evidence entry
- the reused-session run exited with code `0`, returned the same `sessionId` that `drive start` created, and set `managedSession: false`
- the human-readable `landmark_sequence` run printed the pattern id, managed session id, assertion summary, spoken phrases, and item text in the expected text format

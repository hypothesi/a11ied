# Full-Site Audit (Merged into `a11ied`)

This skill has been consolidated into the unified [`a11ied`](../a11ied/SKILL.md) skill (`P2-14` / `N3`).

- For **Quick Page / Component Checks**, see **The dev loop** and **Screen reader recipe** in [`../a11ied/SKILL.md`](../a11ied/SKILL.md).
- For **Full-Site WCAG 2.2 AA Reviews**, use the `review.start` -> `review.next` -> `review.judge` -> `review.report` (or initiation helper `review.run`) workflow in [`../a11ied/SKILL.md`](../a11ied/SKILL.md) and [`resources/run-state-and-decisions.md`](resources/run-state-and-decisions.md).

Collection covers registered states only. Inventory and process coverage require explicit review.
A draft report, successful collection, or green tests do not establish completed conformance.
